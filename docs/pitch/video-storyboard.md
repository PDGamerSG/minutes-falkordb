## How to produce it

1. **Capture.** Use OBS Studio (Display or Window Capture of Chrome, canvas 1920x1080, output scaled from the 1600x900 window, 30 fps), or Windows Game Bar (`Win+Alt+R`) if OBS is not available. Record each shot as its own clip so a fumble costs one shot, not the whole take. Mute desktop audio. Record shots 13, 14 and 16 last, after the rest, because the board actions change the graph; reseed before any retake of them.
2. **Slides.** Present `minutes-pitch.pptx` full screen at 1920x1080 and capture it the same way, or export slides 7, 9, 10 and 12 as PNG (File → Export → PNG) and place them as stills.
3. **Narration, recorded separately.** Read the spoken column of `pitch-script.md` in a quiet room with a USB or headset mic, one paragraph per row, leaving a 1 s pause between rows. Record in Audacity at 48 kHz. Apply noise reduction, normalise to -16 LUFS and remove breaths. The presenter must read the eight speaking notes first.
4. **Align.** In DaVinci Resolve, Clipchamp or Shotcut, lay the narration on the timeline first. Then cut each shot to the row's time range, using the Hold column as the target. Add the caption overlays from the table. Burn in the captions, and also export an `.srt` with the spoken lines for YouTube.
5. **No B-roll.** The earlier hook used `apps/web/public/media/minutes-walkthrough.mp4`; this cut opens on the live landing page instead, so the first frame is the real product. The clip stays available as a fallback for shot 1 (first 8 s, muted; its dates are simplified, so the narration over it stays general).
6. **Export.** 1920x1080, 30 fps, H.264 (High profile), 12 to 16 Mbps VBR, AAC 192 kbps stereo, MP4. The duration must be under 3:00; check it in the player, not just the editor.
7. **Upload.** Upload to YouTube as **Unlisted**. Title: "Minutes: a company memory on FalkorDB that knows what a changed decision affects (Team Vulcan, Graph Hacks 2026)". The description holds the repo link, the live URL if one is verified, the tracks (3, Company Brain, primary; 2, Agent Memory and Coordination), a link to the README disclosure section, and the note that the demo data is synthetic, replays reviewed labels and uses scripted answers unless stated. Upload the `.srt` as subtitles. Paste the link into the README and the submission form.
