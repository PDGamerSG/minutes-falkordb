# Minutes

## Platform

web

## Product purpose

Company Brain for the FalkorDB Graph Hacks Track 3, as requested by Team Vulcan. Connect meetings, emails, decisions, work, and accountable people. Explain current and historical answers through their actual sources. FalkorDB must determine answers and actions.

## Users

The existing prototype serves people reviewing team decisions and commitments. Hackathon judges need to inspect a complete source-to-action demonstration. Production customer research is not yet available.

## Capabilities and constraints

Next.js and FastAPI over FalkorDB. Separate tenant graphs, persistent conversations, source inspection, decision history, agent handoffs, explicit work dependencies, and local follow-up drafts. The local demo uses synthetic sources, gold-label replay, scripted agents and test embeddings. No HTTP authentication yet. No winning, deployment, security, or live-model accuracy claim may be invented.

## Brand commitments

The user requested an elegant, original 3D interface inspired by their Monolith and Chrome references at design.pallabdas.me. They rejected the first pale boxed sculpture / small-type dashboard. Preserve the product name Minutes and all working flows. The user authorized implementation and a frontend agent; that agent has hit its usage limit, so the main thread is finishing the work.

## Evidence

README.md, docs/track3-readiness.md, data/meetings, data/work-items/orbit.json. Live API data supplies every operational count. The decorative sculpture represents connected memory; it is not a visualization of database nodes.

## Confirmed direction

The user selected Chrome: dark, cinematic, reflective metal.
